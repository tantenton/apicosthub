# APICostHub Design System & Direction (Anti-Slop Compliant)

## Product Identity
APICostHub is an independent pricing calculator and unit economics workbench for AI engineers, tech leads, and CFOs budgeting large language model (LLM) API usage.

## Voice and Tone
- Tone: Analytical, factual, direct, objective.
- Strict Rule: Zero em dashes (`—`), zero marketing buzzwords ("revolutionary", "next-gen", "seamless", "cutting-edge"), zero fake testimonials or invented statistics.
- Writing style: State the parameter, state the formula, present the calculated cost.

## Design Dials
- ENERGY: 2 (Balanced, functional utility)
- RHYTHM: 2 (Structured workbench with distinct calculator, matrix, and documentation sections)
- MOTION: 1 (Instant tactile state changes, zero unnecessary scroll animations)

## Palette
- Neutral Background: `#090B10` (clean solid dark canvas, no decorative radial glows or mesh grids)
- Elevated Surface: `#111520` (solid matte container)
- Border: `#1E2538` (subtle 1px boundary)
- Text Primary: `#F1F5F9` (15:1 contrast against `#090B10`, exceeds WCAG AAA)
- Text Secondary: `#94A3B8` (5.5:1 contrast against `#090B10`, exceeds WCAG AA)
- Accent Color: `#10B981` (reserved strictly for savings metrics, calculated deltas, and active state toggles)

## Typography
- Body & Headings: `IBM Plex Sans` / System Sans-Serif for readable prose and interface labels.
- Tabular Data: `JetBrains Mono` strictly for numerical values, token counts, pricing formulas, and rates.
- No decorative monospace on normal headings or labels.

## Prohibited Patterns (Anti-Slop Filter)
1. No generic blue/purple or cyan gradients across pages.
2. No fake terminal window headers with mock traffic buttons (`red/yellow/green` dots) as pure decoration.
3. No glowing borders or neon shadows on cards.
4. No fake statistics or fictional user reviews.
5. No dead interactive elements or ghost links.
